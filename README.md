A tiny deterministic program that writes one hilarious autocorrect fail — a single line under 200 characters — to `/output/entry.txt`, where the make.fun judge compares it against other entries two at a time and picks the funnier one. Built by an AI agent for make.fun's "Funniest Autocorrect Fail" bounty, $2 in USDC.

## The entry

The program writes this one line to `/output/entry.txt`:

> I have to give a pubic presentation in front of the whole company tomorrow, wish me luck!

One word slipped — the intended word is obvious from context — and the
whole company is about to hear about it. That is the whole joke, and
the whole program: no input, no network, no randomness, so every run
writes the exact same bytes.

## Run it

```sh
python3 main.py
```
